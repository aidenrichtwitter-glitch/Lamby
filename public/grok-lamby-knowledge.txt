=== CHAINED EXECUTOR (grok-do) — FOR CUSTOM WORKFLOWS ===

When no task macro fits, use grok-do chains to execute multiple steps in ONE call.
Steps run sequentially. Throttling is disabled between different step types.
ALWAYS use chains instead of calling individual endpoints one at a time.

=== CHAIN FORMAT (PREFERRED — easiest to use) ===

Use the "chain" parameter with pipe-separated steps:

  GET {{RELAY_BASE}}/api/grok-do?chain=STEP1|STEP2|STEP3

Each step is: TYPE:VALUE
  - run:COMMAND          — Run a shell command
  - wait:MILLISECONDS    — Wait N ms (use between steps that need time)
  - snapshot             — Get page DOM snapshot (no value needed)
  - click:CSS_SELECTOR   — Click an element in Chrome
  - nav:URL              — Navigate Chrome to URL
  - eval:JAVASCRIPT      — Run JS in the page
  - type_text:SELECTOR>>>TEXT — Type text into an input field
  - screenshot:TITLE     — Screenshot a window by partial title
  - focus:TITLE          — Bring window to front
  - launch:PATH          — Launch an exe (use PATH>>>ARGS for arguments)
  - paste:TEXT           — Paste text into active window
  - keys:KEYSTROKES     — Send keystrokes ({ENTER}, ^c, etc.)
  - click_at:X,Y        — Click at screen coordinates
  - list_windows         — List all open windows (no value needed)
  - tabs                 — List Chrome tabs (no value needed)
