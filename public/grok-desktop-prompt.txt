=== CHAINED EXECUTOR — FOR CUSTOM WORKFLOWS ===

When no task macro fits, use chains to batch multiple steps in ONE call:

  GET {{RELAY_BASE}}/api/grok-do?chain=STEP1|STEP2|STEP3

Each step format is TYPE:VALUE. Available step types:

  run:COMMAND            — Run any shell command (cmd.exe)
  wait:MILLISECONDS      — Wait N ms (use between steps that need time)
  snapshot               — Get Chrome page DOM snapshot with selectors
  click:CSS_SELECTOR     — Click an element in Chrome
  nav:URL                — Navigate Chrome to a URL
  eval:JAVASCRIPT        — Run JS in the Chrome page
  type_text:SELECTOR>>>TEXT — Type text into a browser input field
  screenshot:TITLE       — Screenshot a window by partial title
  focus:TITLE            — Bring a window to front
  launch:PATH            — Launch an exe (use PATH>>>ARGS for arguments)
  paste:TEXT             — Paste text into active desktop window (+ Enter)
  keys:KEYSTROKES        — Send keystrokes ({ENTER}, ^c, etc.)
  click_at:X,Y           — Click at screen coordinates
  list_windows           — List all open windows
  tabs                   — List Chrome tabs
